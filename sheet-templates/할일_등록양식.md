# 투표 · 스밍 할 일 등록 양식

사용자가 투표 정보(음총팀 X 링크, 사진, 사이트 글)를 주면 이 양식대로 `할일.csv`에 한 줄로 넣어요.
처음 예시: `S4` 퍼스트브랜드 대상 (2026-11-02).

## 칸별 규칙

| 칸 | 쓰는 법 | 예시 (S4) |
|---|---|---|
| 아이디 | 리센느 자체 투표는 `S` + 다음 번호. 연합은 `연합아이디-G1`(줄 것) / `-R1`(받을 것) | `S4` |
| 연합아이디 | 자체 투표는 비워요. 연합이 정해지면 그 연합 아이디 | (빈칸) |
| 구분 | `자체` / `줄 것` / `받을 것` | `자체` |
| 투표종류 | **상 이름**만 짧게 (연도 빼고). 이 이름이 색 · 묶음 기준이 돼요 | `퍼스트브랜드 대상` |
| 내용 (제목) | **투표할 그룹 + 부문**만. 상 이름은 투표종류 칸에 있고 화면 묶음 제목 · 아래 줄에 따로 보이니 제목에 다시 쓰지 않아요. 끝에 ` · 1회` / ` · 매일 3표` 처럼 할 양 | `리센느 여자아이돌(핫트렌드) · 광고모델(여) 부문 · 1회` |
| 플랫폼 | 투표하는 곳. 여러 지역 부문이 있으면 추천 부문을 괄호로 | `퍼스트브랜드 대상 (한국 부문)` |
| 시작일 · 종료일 | `YYYY-MM-DD` | `2026-11-02` · `2026-11-15` |
| 반복 | `매일` / `요일` / `1회`(그날 하루) / `기간 중 1회`(기간 안에 한 번만 하면 끝, 체크가 매일 안 풀려요) | `기간 중 1회` |
| 마감시간 | 알면 `HH:MM`, 모르면 `23:59` | `23:59` |
| 링크 | 투표 페이지 바로가기 (추천 부문 것 하나) | `https://fba.kcforum.co.kr` |
| 메모 | 짧은 문장을 ` · `로 이어요. 순서: 몇 번 하면 되는지 → 어디서 무엇을 고르는지 → 꼭 지킬 것 → 하지 말 것 → 추천 부문 | 아래 참고 |

메모 예시 (S4):
`기간 안에 계정당 한 번만 하면 돼요 · 인물/문화 부문 선택 → 두 부문 모두 리센느 · 이메일 인증까지 해야 투표 완료라 이메일은 정확히 · 두 부문 말고는 연합 협의 중이라 아직 투표하지 말기 · 인도네시아 · 베트남 부문도 있지만 한국 부문만 추천`

## 지키는 것

- **음총팀 공지 출처(X 링크)는 메모에 적지 않아요.**
- **새 상(투표종류)은 별도 묶음으로 나눠요.** `src/00-core.js`의 `GROUPS`에 상 이름 묶음과 색을 추가하고 `campGroup()` 규칙을 넣어요 (다른 묶음과 겹치지 않는 색. 색은 묶음에만 있고 부문마다 따로 정하지 않아요). 순서는 `CAMP_ORDER`. 연합이 생기면 연합 할 일도 같은 묶음에 들어가요.
- 부문 이름에 괄호가 있으면 괄호 앞에 U+2060(줄바꿈 막기)을 넣어 `여자아이돌(핫트렌드)`가 두 줄로 안 갈라지게 해요.
- 사용자가 "한국 부문만" 처럼 추천을 정해 주면 그 부문 링크만 넣고, 다른 부문은 메모에 "있지만 ○○만 추천"으로만 적어요.
- 공지의 "이름 · 전화번호는 아무거나" 같은 안내는 옮기지 않아요.
- 넣은 뒤 `python tools/publish.py "메시지"` 한 번 (CSV 검사 → 버전 올리기 → 30화면 점검 → 올리기 → 실제 사이트 확인). 운영 규칙 전체는 `사용설명서.md`.
- 음방 사전투표도 할 일이라 이 양식대로 `할일.csv`에 넣어요 (사용자 결정 2026-11-04). 투표종류 `음방 사전투표`(이 이름 묶음 아래 음방마다 한 줄), 내용 `음방이름 사전투표 · ○월 ○일(요일) 방송 반영 · 매일 ○표` (리센느 투표라 그룹 이름은 빼요). 반영 방송일은 공지 회차로 확인 (인기가요는 월~금 투표 → 그다음 주 일요일 방송, 결방 주는 건너뜀), 링크는 공지의 투표 바로가기. 예시: `S7` 인기가요. `음방.csv`에는 넣지 않아요 (음방.csv는 출연 · 실시간투표용).
- 음방 실시간투표는 출연 날에 붙는 것이라 `음방.csv` (`tools/music_lineup.py`)로 넣어요.

## 연합 할 일

연합 공지가 오면 상대마다 `줄 것`(상대 후보에게 우리가 투표) · `받을 것`(상대가 리센느에 투표) 한 줄씩 넣어요. 예시: `CORTIS-G2` · `CORTIS-R2` 퍼스트브랜드 대상 (2026-11-02).

- 상대가 `연합.csv`에 없으면 새 줄을 넣어요 (아이디 · 이름 · 팬덤 · 겹치지 않는 색). 총공 계정을 모르면 비워요. 총공팀이 여럿이면(국내 · 해외) 계정을 띄어 써요 (`@국내계정 @해외계정`). 글 링크는 넣지 않고 계정까지만.
- MMA 글로벌 TOP10 은 멜론 · 베리즈에서 따로 진행돼요. 받을 것 내용은 `멜론에서 투표` / `베리즈에서 투표` 로 써서 어디서 보답받는지 보이게 해요.
- 디시 주소는 넣지 않아요. 단 이승윤 연합(`LSY`)의 인증링크 칸에는 사용자 지시로 이승윤 유튜브 갤러리(`gall.dcinside.com/bgsmsylytb`)만 넣어요.
- 아이디는 그 상대의 다음 번호 (`-G2`, `-R2` …).
- 투표종류는 자체 투표와 같은 상 이름으로 써서 같은 묶음에 들어가게 해요.
- MAMA(팬 초이스 · KCONERs' Choice 등) 투표는 인증샷 캡처가 아니라 **투표 인증서**예요. 인증방법에 "투표 인증서를 다운로드 → 낙관·워터마크 붙이기 → 해시태그 넣어 X 인증"으로 적어요. (다른 상은 "투표 완료 화면을 날짜가 보이게 캡처")
- **연합 해시태그는 주는 팬덤이 왼쪽, 받는 팬덤이 오른쪽** (사용자 규칙 2026-11-04). 줄 것은 `#리마인_with_엔돌핀`, 받을 것은 `#엔돌핀_with_리마인`처럼 뒤집어요 (조사도 맞춰서: `#리마인과_앤클로의_…` ↔ `#앤클로와_리마인의_…`). 공지에 리마인 쪽 태그만 있어도 받을 것은 뒤집은 태그로 넣어요.
- 받을 것은 상대가 하는 투표라 `링크` 칸을 비워요.
- 공지에 "뮤직웨이브에 모여 같이 듣기"가 있으면 그 스밍은 뮤직웨이브 줄 하나로만 넣어요 (같은 곡 멜론 스밍 줄을 따로 만들지 않아요). 플랫폼 `멜론 뮤직웨이브 (리센느 음원총공팀)`, 시간대. 인증방법은 다른 연합처럼 쓰되 뮤직웨이브 조건을 앞에: "23시 · 24시 뮤직웨이브로 하루 2회 들으면 X 인증은 필요 없어요. 뮤직웨이브로 못 들으면 완료 화면을 날짜가 보이게 캡처 → 해시태그 넣어 X 인증". 뮤직웨이브만으로 끝나는 연합(X 인증 없음)은 인증방법을 비워요. 예: `PJH-G1`.
- 해시태그 순서는 연합 태그 먼저, 그 뒤에 공통 태그(#RESCENE · #리센느 · #2026MAMAVOTE 등). 사이트도 이 순서로 다시 맞춰서 보여 주고 복사해요.
- 해시태그가 "추후 공지"면 비워 두고 인증방법에 "(해시태그는 추후 공지)"를 적어요. 나오면 채워요.
- 인증 구글폼 · 카톡 링크가 아직 공지되지 않았으면 인증링크 칸에 `구글폼:추후` (또는 `카톡:추후`)를 적어요. 누를 수 없는 "(추후 공지)" 버튼으로 보이고, 링크가 나오면 그 자리를 주소로 바꿔요.
- 자체 투표 메모에도 연합 부문(부문 · 상대)을 한 줄로 보충해요.
- "이 글에 댓글로 인증"이라고 하면 인증링크 칸 맨 앞에 그 X 글 주소(`https://x.com/계정/status/숫자`, `?` 뒤는 빼고)를 적어요. 'X 인증' 버튼이 'X 댓글로 인증'으로 바뀌고, 그 글의 답글 창이 해시태그가 들어간 채로 열려요.

## 음방 주간 스케줄 (일반 안내) · 리센느 음방 출연

음악방송 탭의 "음방 주간 스케줄"은 **리센느 출연과 무관한 일반 음방 안내표**예요 (줄 = 음방 7개, 칸 = 월~일). CSV가 아니라 `src/50-music.js` `MUSIC_SHOWS`에서 그려요: 방송 요일 · 시간(`day` · `time`), 실시간 투표(`live`), 사전투표 기간(`pre.wk` 예: `{ from: '목 12:00', to: '토 12:00' }`, 반영 방송이 다르면 `note`), 음중 시청자위원회(`jury`).

- 음총팀 "음악방송 스케줄러" · "Weekly Scheduler" 같은 그림을 받으면 바뀐 요일 · 시간만 `MUSIC_SHOWS`에서 고쳐요 (`pre.when` 글도 같이). 할 일은 만들지 않아요.
- 리센느 출연("음방 일정 업데이트해줘", "○일 음방 잡혔어")은 이 표에 넣지 않아요. 아래처럼 `음방.csv`에 넣어요.
- 인기가요 · 뮤직뱅크 · 음악중심 출연은 방송사 출연진 공지에서 자동으로 들어와요 (`data/lineup.json`). 공지가 나오기 전에 먼저 알려 주거나 다른 음방이면 직접 넣어요.
- 사전 녹화(사녹)를 한다는 건 그 주 그 음방에 무조건 출연한다는 뜻이에요. 사녹 공지를 받으면 그 주 방송일로 `출연` 줄을 넣어요.
- 리센느 출연은 `음방.csv`에 `출연` 줄로 넣어요 (`python tools/music_lineup.py add --show 음방 --kind 출연 --date YYYY-MM-DD --src 링크`). 그러면 "리센느 일정" 탭과 음악방송 탭 "출연 예정 음방" 두 곳에 같이 보여요. 시간은 음방 기본 시간을 따라요.

| 칸 | 쓰는 법 |
|---|---|
| 아이디 | `M` + 다음 번호 |
| 음방 | 쇼케이팝 / 더쇼 / 쇼챔피언 / 엠카운트다운 / 뮤직뱅크 / 음악중심 / 인기가요 |
| 구분 | `출연` · `실시간투표` · `1위후보` (음방 사전투표는 할 일로) |
| 방송일 | `YYYY-MM-DD` |
| 시작 · 종료 | 보통 비워요 (음방 기본 시간을 따라요) |
| 메모 | 짧은 설명 (`컴백 첫 주`, 실시간투표의 `문자 #0505` 등) |
| 출처 | 확인한 공지 · 편성 주소 |

## 리센느 일정에 직접 넣는 일정 (`data/weekly.json`)

투표가 아닌 일정(팝업 · 이벤트 · 신청 마감 등)은 `data/weekly.json`의 `events`에 한 줄 넣어요. "리센느 일정" 탭에 보여요 (관리자 모드 "리센느 일정").

| 칸 | 쓰는 법 |
|---|---|
| id | `x` + 날짜 + 짧은 영문 이름 (`x20261103photoism`) |
| date · end | 시작일 · 종료일 `YYYY-MM-DD`. 하루 일정이나 "마감일만"이면 둘 다 같은 날 |
| time | 알면 `HH:MM`, 모르면 빈칸 |
| category | 이벤트 / 공연 / 방송 / 발매 / 기타 … |
| title · note · link | 제목 · 설명(기간 등) · 바로가기 |

- **여러 날 이어지는 일정(팝업 · 이벤트 등)은 date에 시작일, end에 종료일을 꼭 넣어요.** 일정 화면이 시작일(`시작`)과 종료일(`종료`)에 각각 보여 줘요 (전 달에 시작했으면 1일에 `진행 중`). blip · Mnet Plus 일정도 같은 방식이에요.
- 제목이 같은 날 blip · Mnet Plus 일정과 낱말이 겹치면 숨겨져요. 다른 일정이면 제목 낱말을 다르게 쓰고 자세한 건 note에.
