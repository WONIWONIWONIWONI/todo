# 고장 났을 때

코딩을 몰라도 따라 할 수 있게 적었어요. 먼저 **관리자 화면 맨 위 신호등**(자동 작업 4개)을 보세요. 빨간 칸을 누르면 그 작업의 기록이 열려요.

비밀번호·쿠키·토큰 값은 채팅방이나 문서에 적지 않아요. 어떤 값이 어디에 있는지는 [비밀값 목록](비밀값목록.md)에 있어요.

## 1. 새 공지가 안 들어와요 (신호등 "X 새 글"이 빨강)

가장 흔한 원인은 수집용 X 계정의 로그인이 풀린 거예요.

1. 급한 공지는 기다리지 말고 관리자 화면의 해당 탭에서 **새 줄**로 직접 넣어요. 사이트는 이것만으로 정상 운영돼요.
2. 관리자 화면 → 받은 공지 → **지금 X 새 글 받기**를 한 번 눌러 봐요. 초록이 되면 끝.
3. 계속 빨강이면 수집용 X 계정으로 브라우저에서 다시 로그인하고, 새 쿠키 두 개(`auth_token`, `ct0`)를 GitHub 저장소 → Settings → Secrets and variables → Actions 의 `X_AUTH_TOKEN`, `X_CT0`에 다시 넣어요.
4. X가 계정을 막았다면 풀릴 때까지 1번 방식(직접 입력)으로 운영해요. 막힌 것을 피해 가려는 시도는 하지 않아요.

## 2. 고쳤는데 사이트가 안 바뀌어요

1. 2~3분 기다린 뒤 사이트 오른쪽 위 **새로고침** 버튼을 눌러요. 홈 화면 앱은 완전히 껐다 켜요.
2. 관리자 화면에 반영 상태나 실패 안내가 보이면 **자세히 보기**를 눌러요. 빨간 X 표시가 있는 단계의 이름을 확인해요.
   - "검사"에서 멈춤: 입력한 칸에 틀린 곳이 있어요. 안내된 줄을 고치고 다시 **검사 후 반영**.
   - "충돌"에서 멈춤: 다른 사람이 먼저 고쳤어요. 초안을 내려받고 최신 자료를 다시 연 뒤 필요한 줄만 다시 넣어요.
   - 그 밖: **저장한 초안 다시 반영**을 한 번 눌러요. 두 번 실패하면 실패 화면 주소를 담당자(또는 AI)에게 보내요.
3. 입력한 내용은 실패해도 초안으로 남아 있어요. 다시 입력하지 않아도 돼요.

## 3. 관리자 화면에 로그인이 안 돼요

- "비밀번호가 달라요": 비밀번호를 확인해요. 1분에 5번 넘게 틀리면 1분 기다려야 해요.
- "관리자 로그인을 지금 사용할 수 없어요"·"서버에 닿지 못했어요": 저장 서버(Cloudflare) 쪽 문제예요. Cloudflare 계정 주인이 대시보드 → Workers → `rescene-admin` 이 켜져 있는지 확인해요.
- 30일이 지나면 자동으로 로그아웃돼요. 다시 로그인하면 돼요.

## 4. 비밀번호를 바꾸고 싶어요 / 누가 알아낸 것 같아요

Cloudflare 계정 주인이 컴퓨터에서 `admin-worker` 폴더를 열고 아래 두 줄을 차례로 실행해요. 물어보면 새 값을 입력해요.

```
npx wrangler secret put ADMIN_PASSWORD
npx wrangler secret put SIGN_KEY
```

`SIGN_KEY`(아무 긴 글자)를 바꾸면 모든 기기가 로그아웃돼요. 그 뒤 새 비밀번호를 운영자에게만 따로 알려 줘요.

## 5. 일정(blip·Mnet Plus)이나 음방 편성표가 옛날 내용이에요

1. 관리자 화면 맨 위 **전부 새로 받기**를 눌러요. 1~2분 뒤 초록이면 끝.
2. 빨강이면 그 사이트(blip, Mnet Plus, 방송사)가 잠시 안 되거나 화면 구조를 바꾼 거예요. 하루 뒤에도 빨강이면 담당자(또는 AI)에게 빨간 칸을 눌러 나온 주소를 보내요.
3. 그동안 틀린 일정은 관리자 → 리센느 일정 → **일정 보정**으로 직접 고칠 수 있어요.

## 6. 그래도 모르겠으면

이 세 가지를 담당자(또는 AI)에게 보내요: ① 무엇을 하려고 했는지 ② 화면에 나온 글 그대로(캡처) ③ 빨간 칸이나 **자세히 보기**를 눌러 나온 주소.
