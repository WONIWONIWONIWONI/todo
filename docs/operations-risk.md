## 무료 자동화의 운영 범위

- 이 저장소는 공개이며 워크플로는 표준 Ubuntu 러너를 사용한다. 공개 저장소 표준 러너 실행 시간은 무료다. GitHub 예약은 지연될 수 있고, 공개 저장소 활동이 장기간 없으면 예약이 비활성화될 수 있다. 무료 운영이 정시 실행을 보장하지 않는다. [Actions 과금](https://docs.github.com/en/billing/concepts/product-billing/github-actions) · [예약 실행](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)
- 기본 Worker 호출 주기는 X 10분, blip 30분, 음방 3시간, 점검 하루 1회다. 정상 하루에는 **144 + 48 + 8 + 1 = 201회**의 워크플로 호출이 예상된다. 이는 외부 HTTP 요청 수와 다르다. 한 번의 일정 수집에서도 여러 달을 조회한다. 수동 실행과 예비 예약은 별도다.
- Workers 정적 파일 제공은 무료·무제한이다. 관리자 Worker 실행, Durable Objects, GitHub API, 각 자료 제공자의 제한은 별도다. 계정 전체의 실제 사용량과 외부 제공자의 수집 허가는 이 점검으로 확인되지 않았다. [정적 파일 과금](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/) · [Workers 제한](https://developers.cloudflare.com/workers/platform/limits/)
- 확인 순서는 최근 Actions의 성공·실패 → 원본이 실제로 바뀌었는지 → 메인 반영 → 미러 반영이다. 신규 공지가 없는 정상 실행에서도 데이터 파일 시간은 그대로일 수 있다. 관리자에게 증상이 남으면 원문·발생 시각·실행 링크를 인계한다.

## 재현과 남은 검증

관리자 요청은 테스트 키·모의 저장소로 검증한다. `node --test tests/*.test.mjs`와 `python -m unittest discover -s tests -p 'test_*.py'`에서 인증 누락, 비허용 푸시 주소, 초안 충돌, 부분 수집 실패 및 백업 예약 판정을 재현한다. 실제 계정 잠금·휴대폰 푸시·외부 장애를 유발하는 시험은 하지 않는다. 이 항목과 AI-0009 실기기 검증은 담당자가 시험 기기와 테스트 자료를 확보한 뒤 확인한다.
