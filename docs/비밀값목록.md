# 비밀값 목록

값은 여기에 적지 않아요. **이름 · 있는 곳 · 바꾸는 법**만 적어요. 값을 채팅·문서·커밋에 남기지 않아요.

| 이름 | 무엇에 쓰나 | 있는 곳 | 바꾸는 법 | 만료·주의 |
|---|---|---|---|---|
| `ADMIN_PASSWORD` | 관리자 화면 로그인 | Cloudflare `rescene-admin` 워커 | `admin-worker` 폴더에서 `npx wrangler secret put ADMIN_PASSWORD` | 운영자끼리만 공유 |
| `SIGN_KEY` | 로그인 유지(30일) 서명 | Cloudflare `rescene-admin` 워커 | `npx wrangler secret put SIGN_KEY` | 바꾸면 모든 기기 로그아웃 |
| `GH_TOKEN` | 워커가 GitHub 자료를 읽고 쓰고 자동 작업을 실행 | Cloudflare `rescene-admin` 워커 | GitHub → Settings → Developer settings → Fine-grained tokens 에서 새로 만들어(이 저장소만, Contents 쓰기 + Actions 쓰기) `npx wrangler secret put GH_TOKEN` | **만료일이 있어요.** 만료되면 저장·자동 수집이 한꺼번에 멈춰요. 만료일을 달력에 적어 두세요 |
| `X_AUTH_TOKEN`, `X_CT0` | 음총팀 X 공지 수집 | GitHub 저장소 → Settings → Secrets and variables → Actions | 수집용 X 계정으로 다시 로그인해 쿠키 `auth_token`, `ct0` 값을 넣기 | 로그아웃·비밀번호 변경 시 무효. 개인 본계정 말고 수집용 계정 사용 |
| `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID` | GitHub Actions가 워커를 배포 | GitHub 저장소 → Settings → Secrets and variables → Actions | Cloudflare 대시보드 → My Profile → API Tokens 에서 새로 만들어 넣기 | 토큰에 만료일을 걸었다면 그날 배포가 멈춰요 |

알림 열쇠(VAPID)는 워커가 스스로 만들어 보관해요. 따로 넣을 값이 없어요.

## 사고가 났을 때 (값이 새어 나간 것 같을 때)

1. 새어 나간 값을 위 "바꾸는 법"대로 바로 바꿔요.
2. 관리자 비밀번호라면 `SIGN_KEY`도 함께 바꿔 모든 기기를 로그아웃시켜요.
3. GitHub 저장소 → Commits 에서 모르는 "관리자 초안" 커밋이 있는지 확인해요.
